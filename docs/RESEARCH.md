## Import discipline

`scripts/acquire_statscell.py` obtains only public GitHub commit metadata, the public JSON and repository license. It pins the returned commit, hashes original bytes and stages normalized records without inventing verification dates. Unknown patch and effective dates remain unknown. It does not extract or patch any game client.

Combat packs use a stricter schema: a value, unit, source URL/description, source identifier, verification date, effective date, game version and confidence classification for every numeric statistic. A reviewer must provide missing information or explicitly use assumed fixture values. Pack IDs remain immutable so previous job inputs stay reproducible.

No official API credentials were requested or configured during this build. No private endpoints, credentials, screenshots, replays or account data were acquired from other people.
